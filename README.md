# foodan-dev.github.io

## 项目介绍

**旦食** App 官网

## 项目架构

基于 Vue 3 + TypeScript + Vite 构建的静态网站，使用 Element Plus 作为 UI 框架。

## 项目技术栈

- Vue 3
- TypeScript
- Vite
- Element Plus
- Vue Router
- Vuex
- Pinia

## 项目目录结构

```text
├── public/
├── src/
│   ├── assets/
│   ├── components/
│   ├── views/
│   ├── App.vue
│   └── main.ts
├── .gitignore
├── index.html
├── package.json
├── README.md
```

## 项目安装

```bash
npm install
```

## 项目运行

```bash
npm run dev
```
